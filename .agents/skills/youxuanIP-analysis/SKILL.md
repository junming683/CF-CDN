# CDN 优选域名分析工具 (youxuanIP-analysis)

当用户发送包含 CDN 节点测速数据（格式：`速度 MB/s | 延迟 ms : 域名`）的 .txt 文件附件时，自动解析并按照以下模板输出。

## 输入格式

文件内容每行格式如下：
```
5.61 MB/s | 38.6 ms : openai.com
0.99 MB/s | 122.8 ms : www.shopify.com
0.44 MB/s | 38.4 ms : gh-proxy.com
```

## 解析规则

1. **提取数据**：逐行解析 `速度 | 延迟 : 域名` 格式，提取速度值(MB/s)、延迟值(ms)、域名。
2. **分类筛选**：
   - **综合最佳优选**：按速度从高到低排序，选取 Top4 域名。同时兼顾延迟，若延迟过高（>300ms）则顺延下一个。
   - **高带宽 / 大流量优选**：排除综合最佳已用的域名后，选取速度排名 Top4 的域名。优先选择内容/基础设施类域名。
   - **极低延迟优选**：排除已用域名后，按延迟从低到高排序，选取延迟 <100ms 的域名 Top4。如果不足4个则放宽到 <150ms 补齐。
   - **数量控制**：每类严格输出 **4 个域名**。
   - **原则**：三个类别之间域名互不重复。
3. **输出模板**：严格按照以下模板。

## 输出模板

```
按分类及纯域名列表整理如下，方便直接复制：

一、 综合最佳优选

{domain1}
{domain2}
{domain3}
{domain4}

二、 高带宽 / 大流量优选

{domain1}
{domain2}
{domain3}
{domain4}

三、 极低延迟优选

{domain1}
{domain2}
{domain3}
{domain4}
```

## 注意

- 如果文件不符合 `速度 | 延迟 : 域名` 格式，不要强行解析，提示用户文件格式不匹配。
- 输出的域名按速度或延迟从优到劣排序。
- 纯文本输出，不要使用 markdown 代码块（```）。
- 如果用户没有提供附件而是直接提问，请先索要测速数据文件。
- 每类标题下直接输出域名列表，一行一个。
