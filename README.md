# 🚀 CF-CDN 域名/IP 真实带宽与延迟双重测试工具

这是一个轻量级、跨平台的 **Cloudflare (CF) CDN 域名/IP 真实带宽与延迟测速工具**。特别针对 **Android Termux** 进行了优化，同时支持 Linux、macOS 与 Windows。

---

## ✨ 核心特性

- ⚡ **双阶段智能测速（真·优选）**：
  1. **阶段一（快速过滤）**：并发 Ping 测试，3 秒内筛选出延迟最低的前 35 个候选节点。
  2. **阶段二（并发真实带宽测试）**：对低延迟节点进行 **HTTP 实际下载速度测试 (MB/s)**，彻底解决“Ping 值低但下载慢”的问题。
- 📊 **按真实下载速度降序排序**：优先推荐实际带宽最高、最流畅的节点。
- 🔝 **双格式自动导出**：
  - `CDNym_clean.txt`：纯域名列表（按下载速度排序，无前缀，方便手机端直接长按全选复制）
  - `CDNym.txt`：包含真实 MB/s 速度与 Ping 延迟的详细导出
- 📱 **Termux 专属快捷命令**：在 Android 手机/平板 Termux 安装后，直接输入 `cfcdn` 即可随时测试。
- 📝 **支持自定义域名/IP 库**：支持读取 `domains.txt`，可自由添加或更新你的节点库。

---

## 📲 安卓 Termux 安装与使用教程

### 1. 一键下载与安装

打开 Android 手机/平板上的 **Termux** app，复制并运行以下命令：

```bash
git clone https://github.com/junming683/CF-CDN.git && cd CF-CDN && bash install.sh
```

### 2. 运行测试

安装完成后，可以在 Termux 任意路径直接输入：

```bash
cfcdn
```
