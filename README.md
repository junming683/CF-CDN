# 🚀 CF-CDN 智能多网/多运营商 Cloudflare 真·测速工具

这是一个轻量级、跨平台的 **Cloudflare (CF) CDN 域名 / IP 真实带宽与延迟双重测速工具**。

特别针对 **中国电信、中国移动、中国联通** 不同的跨境路由与 QoS 特性进行了精准分流优化，内置自动同步 **vps789.com** 与 **ipdb.api.030101.xyz** 实时优选数据库，支持 **Android Termux、Linux、macOS 与 Windows**。

---

## ✨ 核心特性

- 🌐 **多源在线 API 自动同步（新增）**：
  - 📡 **vps789.com**：24小时全网监控，自动提取 `CT (电信)`、`CM (移动)`、`CU (联通)` 与 `AllAvg` 专属优质节点。
  - ⚡ **ipdb.api.030101.xyz**：实时拉取官方 `bestcf` 优选 IP 与 `bestproxy` 反代优质节点。
  - 🔄 **cf.090227.xyz**：动态补充三网活跃节点，支持多源容灾故障转移。
- 🎯 **运营商专属路由优化**：
  - **中国电信**：锁定美西直连/大带宽抗丢包节点（SJC/LAX），自动排除 30ms 亚洲假低延迟与晚高峰绕路黑洞。
  - **中国移动**：锁定香港/新加坡/日本 CMI 骨干直连节点，畅享真实低延迟与高速吞吐。
  - **中国联通**：锁定美西直连与亚洲 AS4837 优质节点。
  - **三网全量通用**：聚合所有在线 API 与全量 1000+ 节点库。
- ⚡ **双阶段智能真·测速**：
  1. **阶段一（高并发 Ping 探测）**：并发测试 3 次取平均延迟，自动按运营商专属门槛快速筛选。
  2. **阶段二（真实带宽下载测试）**：采用 Cloudflare 官方真实数据流（带 TLS SNI / Host 伪装），支持纯 IP 与域名测出真正的 **MB/s 下载吞吐量**，彻底解决“测速看着快、实际用着卡”的痛点。
- 📊 **智能分类输出（Top 4 推荐）**：
  - 🏆 **综合最佳优选**（兼顾延迟与速度）
  - ⚡ **高带宽 / 大流量优选**（适合 4K 视频、大文件）
  - 🚀 **极低延迟优选**（适合网页浏览、实时通讯）
- 📋 **纯节点直复制区域**：每类域名/IP 单独一行，行间留白，方便手机/电脑端直接长按框选复制。
- 🧪 **VLESS 订阅节点真实测速（菜单选项 6）**：拉取优选订阅 → 断开 VPN 后真机直连实测 VLESS+WS+TLS 真实吞吐 → **自动剔除离线/测速失败节点** → 按速度降序重排并追加 `[xx.xxMB/s]` 标签 → 结果自动写入手机剪贴板，同时备份到 `/sdcard/CF-CDN/`（未安装 termux-api 时自动改为逐条打印节点链接）。
- 📱 **多并发模式与内存保护**：支持极速模式、稳定模式（防 Android Termux OOM 崩溃）及精简快测模式。
- 📁 **双格式自动保存**：
  - `CDNym_clean.txt`：纯节点列表
  - `CDNym.txt`：包含详细带宽与延迟的测速报告
  - （Android Termux 环境下自动写入 `/sdcard/CF-CDN/`，文件管理器直接可见）

## 📲 安装与使用教程

### 1. 安卓 Termux 一键安装

打开手机/平板上的 **Termux**，复制并运行以下命令：

```bash
git clone https://github.com/junming683/CF-CDN.git && cd CF-CDN && bash install.sh
```

安装完成后，在 Termux 任意路径直接输入以下命令即可运行：

```bash
cfcdn
```

---

### 2. Windows / macOS / Linux 运行

确保已安装 Python 3，克隆仓库后直接运行：

```bash
git clone https://github.com/junming683/CF-CDN.git
cd CF-CDN
python cfcdn.py
```

## 💡 客户端配置防坑指南

测出优质 IP / 域名后，在代理客户端或反代配置中请按以下规范填写：

| 配置项 | 正确填法 | 说明 |
| :--- | :--- | :--- |
| **连接地址 (Address)** | 填工具测出的 **优选 IP** 或 **优选域名** | 实际建立 TCP/TLS 连接的节点 |
| **伪装域名 (Host / SNI)** | **必须填你自己节点的真实域名** | 保证 TLS 证书校验通过，绝不卡顿！ |
| **端口 (Port)** | `443` 或 `8443` / `2053` / `2083` / `2087` / `2096` | 若晚高峰 443 被限速，可切换备用 HTTPS 端口 |
